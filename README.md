# 🛒 Fresh to Rely — Grocery eCommerce App

A full-stack grocery shopping web application built with
the MERN stack. Users can browse products, manage their
cart, place orders and track order history.

## 🚀 Tech Stack

**Frontend**
- React.js
- Redux (cartSlice, productSlice, userSlice)
- Context API (AuthContext, CartContext)
- CSS

**Backend**
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## 📱 Screens

| Screen | Description |
|--------|-------------|
| Login | User login with JWT auth |
| Register | New user registration |
| Home | Landing page with featured products |
| Products | Browse all grocery items |
| Cart | Manage selected items |
| Checkout | Place order |
| Orders | View order history |
| Profile | Manage user details |

## ✨ Features

- JWT based secure authentication
- Product listing and search
- Add to cart and quantity management
- Order placement and history
- User profile management
- Fully responsive UI

## 🔄 App Flow

User Registers → Browses Products → Adds to Cart
→ Proceeds to Checkout → Order Placed → View in Orders
